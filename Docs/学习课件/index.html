阶段 0 · 全局概览

不抠细节，用你已亲手跑通的那条链路当地图，把整个框架一次性串起来。

一、三个核心心智模型（先装进脑子）

① Scene 是一切的容器和生命周期边界

「Gate 场景」「Map 场景」都是 Scene。所有 Entity 都活在某个 Scene 里；销毁一个 Scene 会级联销毁其下所有东西。想用框架功能（定时器、事件、网络、数据库），都通过 self.Scene 上挂的组件拿到。找不到入口时，先看 Scene。

② 零反射 =「定义即注册」

由 Fantasy.SourceGenerator 在编译期把每个 Handler/System/协议/场景类型生成成注册代码。所以：写个 Handler 类它就自动被路由（绝不手动注册）；改协议/配置后要重新构建；*.g.cs 与 Generate/ 产物绝不手改，改源头。

③ Entity 不 new，异步不用 Task

Entity/Component 通过工厂创建（带对象池、零 GC），都是 sealed class；所有异步一律 FTask。

附录 A · 验证工具速查

  • 启停服务器：Unity 菜单 Fantasy/服务端配置（或 Fantasy/启动服务端 / 停止服务端）。
  • 命令行：dotnet run --project examples/Server/APP/Main/Main.csproj -c Debug --framework net8.0 -- --m Develop（--framework 和 --m 都必需）。
  • 启动成功：日志 Process:1 Startup Complete SceneCount:7。监听 KCP 20000、WebSocket 20001、HTTP 20010、Inner TCP 11001–11007。
  • 客户端验证：Unity 进 Play，Console 看 [Fantasy] ... 往返日志。
  • 改协议后：务必重新运行协议导出，确认两侧 opcode 一致。数据库章节需本机 MongoDB。

附录 B · 速查表（命令 / 约定）

铁律约定

异步用 FTask，不用 Task Entity/Component/Handler = sealed class namespace Fantasy;（文件作用域） Entity 不 new，用工厂+对象池 错误用 response.ErrorCode Log.Debug/Info/Error 绝不手改 *.g.cs / Generate 绝不手动注册 Handler/System

编译期硬要求

  • 编译常量 FANTASY_NET（服务端）/ FANTASY_UNITY（Unity）。
  • AllowUnsafeBlocks=true；Fantasy.SourceGenerator 作为 Analyzer 引用。
  • Fantasy.config 既 AdditionalFiles 又 CopyToOutputDirectory=Always。

客户端连接（Unity）

// 协议按 FANTASY_WEBGL 自动切：WebGL→WebSocket(20001)，原生→KCP(20000)
Session = Scene.Connect(address, FantasyNetworkConfig.Protocol,
    onComplete, onFail, onDisconnect, false, 5000);
Session.AddComponent<SessionHeartbeatComponent>().Start(2000);   // 心跳，别漏
var resp = await Session.C2G_LoginGameRequest(account);          // RPC

服务端 Handler 骨架

// 普通消息（无返回）
public sealed class C2G_XxxMessageHandler : Message<Session, C2G_XxxMessage>
{
    protected override async FTask Run(Session session, C2G_XxxMessage message)
    {
        await FTask.CompletedTask;
    }
}

// RPC（请求-响应）
public sealed class C2G_XxxRequestHandler : MessageRPC<Session, C2G_XxxRequest, G2C_XxxResponse>
{
    protected override async FTask Run(Session session, C2G_XxxRequest request, G2C_XxxResponse response, Action reply)
    {
        // 失败：response.ErrorCode = ...; 成功留 0
        await FTask.CompletedTask;
    }
}
